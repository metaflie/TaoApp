# ტაო — მზა ვერსია (Node.js-ის გარეშე)

ეს ფოლდერი შეიცავს აპლიკაციის აწყობილ ვერსიას ერთ `index.html` ფაილში (კოდი, სტილები, შრიფტები და ხმები შიგნითაა).

გახსნა:
- VS Code-ში: `standalone/index.html` → მარჯვენა ღილაკი → **Open with Live Server**; ან
- უბრალოდ ორჯერ დააჭირე `index.html`-ს — გაიხსნება ბრაუზერში.

დეველოპმენტისთვის (კოდის შესაცვლელად) გამოიყენე `npm install` და `npm run dev` (საჭიროა Node.js 20.19+).
