# ტაო (TAO) — ქართული დამწერლობის სასწავლო ვებაპლიკაცია

**ავტორი:** გიორგი არჩემაშვილი · SkillWill College · 2026

ტაო არის საგანმანათლებლო ვებაპლიკაცია, რომელიც ასწავლის ქართული დამწერლობის სამ ისტორიულ ფორმას — **ასომთავრულს, ნუსხურსა და მხედრულს** — ინტერაქციული გაკვეთილების, ტესტების, ლექსიკონისა და წერის სავარჯიშოების საშუალებით. ვიზუალი აწყობილია Figma-ს მაკეტების მიხედვით (დესკტოპი + რესპონსიული ვერსია).

---

## გაშვება VS Code-ში

**საჭიროა:** [Node.js](https://nodejs.org) 20.19+ ან 22+ (LTS) და VS Code.

1. გახსენი ZIP და VS Code-ში აირჩიე **File → Open Folder…** → `tao-app` ფოლდერი.
2. გახსენი ტერმინალი: **Terminal → New Terminal** (ან `` Ctrl+` ``).
3. დააყენე დამოკიდებულებები:
   ```bash
   npm install
   ```
4. გაუშვი დეველოპმენტის სერვერი:
   ```bash
   npm run dev
   ```
5. ბრაუზერში გახსენი მისამართი, რომელსაც ტერმინალი აჩვენებს (ჩვეულებრივ **http://localhost:5173**).

| ბრძანება | დანიშნულება |
| --- | --- |
| `npm run dev` | დეველოპმენტის სერვერი (Hot Reload) |
| `npm run build` | საბოლოო (production) ვერსიის აწყობა `dist/` ფოლდერში |
| `npm run preview` | აწყობილი ვერსიის ლოკალური ნახვა |
| `npm run lint` | კოდის შემოწმება (oxlint) |

> სატესტოდ შექმენი ანგარიში „რეგისტრაციის“ გვერდზე — მონაცემები ბრაუზერში ინახება, სერვერი საჭირო არ არის.

## ტექნოლოგიები

- **React 19** + **Vite** — კომპონენტებზე დაფუძნებული ინტერფეისი, სწრაფი აწყობა
- **React Router** — ნავიგაცია, დინამიკური მარშრუტები (`useParams`, `useSearchParams`), დაცული მარშრუტი
- **Redux Toolkit** — პროგრესისა და სესიის საერთო მდგომარეობა
- **React Context** — ენის გადამრთველი (ქართული / English)
- **localStorage** — პროგრესისა და ანგარიშების ლოკალური შენახვა (try/catch დაცვით)
- **Web Crypto API** — პაროლის SHA-256 ჰეშირება
- **Canvas API** — წერის სავარჯიშო (Pointer Events, მაუსი და შეხება)
- **Web Speech API** — სიტყვის წარმოთქმა (თუ ბრაუზერს ქართული ხმა აქვს)
- **CSS3** — ცვლადები, Flexbox, Grid, მედია-მოთხოვნები (1180 / 900 / 640px), ანიმაციები
- **Unicode** — ასომთავრული (U+10A0), ნუსხური (U+2D00), მხედრული (U+10D0); შრიფტები: Inter, Noto Sans Georgian
- `React.lazy` + `Suspense` — გვერდების ცალკე ჩატვირთვა (code splitting)
